# CTF · 정보보안기사 · 모의해킹 병행 학습

기간과 순서는 정하지 않는다. 원하는 때 분야를 골라 문제 풀이·개념 학습·보고서를 이어간다.
실행 방법은 [개발 안내](development.md)를 참고한다.

## 1. CTF

- 기초·웹·포렌식·암호·리버싱·시스템·네트워크의 100개 문제를 제공한다.
- 먼저 독립적으로 시도하고 필요할 때 힌트를 확인한다.
- 서버에서 flag를 검사하며 같은 문제는 중복 득점하지 않는다.
- 정답 후 풀이와 방어 과제를 기록한다. 힌트를 사용했거나 설명을 참고했다면 기록에 남긴다.

## 2. 정보보안기사

| 필기 과목            | 개념 학습                 | 자체 제작 필기 연습 | 실기 연결        |
| -------------------- | ------------------------- | ------------------- | ---------------- |
| 시스템보안           | 권한, 계정, 로그          | 20문항              | 권한 진단 서술   |
| 네트워크보안         | TCP·UDP, 방화벽, DNS·TLS  | 20문항              | 방화벽 변경 계획 |
| 어플리케이션보안     | SQL, XSS, 세션·인가       | 20문항              | 안전한 쿼리 수정 |
| 정보보안일반         | CIA, 암호, 위험           | 20문항              | 기술 선택 근거   |
| 정보보안관리 및 법규 | 정책, 개인정보, 사고 대응 | 20문항              | 사고 대응 서술   |

개념 15개는 핵심 설명·사례·자가점검·관련 CTF로 구성된다.
100문항 모의고사는 학습 모드와 150분 시험 모드를 제공한다. 답안을 임시 저장해 이어 풀고, 제출 후 과목별 점수·과락·오답을 확인한다. 개별 필기 연습의 마지막 오답과 모의고사 응시 기록은 구분한다.
실기 서술은 먼저 답안을 작성하고 평가 기준과 비교한다. 자동 채점은 하지 않는다.

이 자료는 입문 보조 자료이며 기출문제·공식 모범답안이나 전체 시험 범위가 아니다. 소수 연습 문제의 정답률로 합격을 예측하지 않는다.
과목과 시험 방법은 [KCA 공식 안내](https://www.cq.or.kr/qh_quagm01_020.do)를 2026-11-16에 확인했다. 응시자격·일정·출제기준·법규는 접수 전 다시 확인한다.

## 3. 모의해킹

100개 시나리오를 접근 제어·인증·입력 처리·브라우저·API·시스템·DB·네트워크·설정·보고서로 나눠 학습한다. 가상 자료와 로컬 도구로 다음 과정을 반복한다.

1. 진단 범위·승인·제외 대상·중지 조건 정의
2. 문서 접근 제어 진단: 요청 비교 도구로 취약·수정 버전 검사
3. SQL 코드 리뷰: 원인 분석, 바인딩 수정, 정상 기능 검증
4. 댓글 출력 진단: 출력 문맥, 텍스트 처리, 영향 입증 범위
5. 세션 점검: 로그아웃 후 재사용과 서버 무효화
6. 발견사항 보고: 근거·영향·수정·재검증·한계 정리

각 실습의 자료는 다운로드 가능하다. 보고서는 웹 노트에 저장하거나 [보고서 양식](templates/security-report.md)를 사용한다. 완료는 본인이 검토한 과제만 표시한다.

## 세 가지를 연결하는 방법

| 주제 | CTF              | 기사                | 모의해킹                     |
| ---- | ---------------- | ------------------- | ---------------------------- |
| 권한 | 권한 숫자 문제   | 시스템보안          | 범위·최소 권한 검토          |
| 인가 | 문서의 진짜 주인 | 세션과 접근 제어    | 타인 문서 접근 재현·수정     |
| 로그 | 접근 기록 분석   | 증거 보존·사고 대응 | 영향과 미확인 범위 구분      |
| 암호 | XOR·ROT13        | 암호·해시·서명      | 노출된 정보와 보호 방법 분석 |

CTF 점수, 필기 결과, 수동 완료, 노트 수는 서로 다른 지표다. 문제 해결 수를 실무 숙련도나 자격 취득과 동일하게 취급하지 않는다.

## 다음 작업을 고르는 기준

- 새 개념이 이해되지 않으면 관련 개념과 작은 CTF 문제로 돌아간다.
- 필기 오답이 생기면 해설과 관련 개념을 읽고 자신의 말로 정리한 뒤 다시 푼다.
- 풀이를 설명할 수 있으면 수정과 정상·비정상 입력 재검증을 추가한다.
- 모의해킹 보고서는 실제 확인한 사실과 참고 사례·추정을 구분한다.
- 포트폴리오에는 완성된 근거, 코드, 수정 전후 결과를 남긴다.

## 코드 짜기

1. HTML 12과제로 제목·링크·이미지·목록·표·폼·문서 구조를 익힌다.
2. CSS 12과제로 색상·여백·배치·반응형을 직접 작성한다.
3. 사이트 제작 6단계에서 앞 단계 코드를 이어받아 포트폴리오 사이트를 완성한다.

왼쪽에서 작성하고 Control + R로 실행하면 오른쪽에서 화면과 검사 결과를 확인한다. Command + R은 새로고침이다. 이론·힌트·예시 풀이를 참고하되 그대로 외우기보다 내용을 바꾸며 결과를 확인한다. 코드는 이 브라우저에 자동 저장되며 완성한 HTML은 내려받아 보관한다.
